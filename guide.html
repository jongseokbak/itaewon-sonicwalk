1. 앱: 이태원 소닉워크

2026-11-26(목) 점심·저녁 두 차례, 동일 코스를 동일 순서로 걸으며 녹음. 앱은 이 녹음을 현재 위치 기준으로, 또는 구간 선택으로 재생. 웹페이지를 홈 화면에 추가하는 방식(PWA)으로, 앱스토어 설치 불필요.

버전내용

구간(지점, 지점 사이 길)별로 버전 개별 지정 가능. 예: 10.29 골목은 1 낮, 다음 길은 3 겹침.

사전 준비 (와이파이, 1회)

  1. 휴대폰으로 앱 주소 열기. 아이폰은 Safari 사용.
  2. 홈 화면에 추가. 아이폰: 하단 공유 버튼 → 홈 화면에 추가. 안드로이드: 크롬 우상단 ⋮ → 앱 설치(또는 홈 화면에 추가).
  3. 홈 화면의 소닉워크 아이콘으로 실행.
  4. 상단 오프라인 저장 칸에 참가 비밀번호 입력 → 확인.
  5. 사용할 버전의 저장 누르기. 버전당 60–90MB, 받은 뒤 기기 안에서 잠금 해제. 구간별로 다른 버전을 쓸 경우 해당 버전 모두 저장.
  6. 위치 사용 요청 시 허용.

아이폰 주의: 3번 필수. Safari 창에서 저장한 소리는 홈 화면 앱에서 보이지 않음. 반드시 홈 화면 아이콘으로 실행한 뒤 저장.

저장 후에는 데이터 연결 없이 실행·재생 가능.

구간 골라 듣기 (기본 화면)

위치와 무관하게 9개 구간(해설 지점 5, 지점 사이 길 4)을 선택 재생. 사전 청취, 사후 낮·밤 비교용.

  • 구간 칸 누르기 → 상단 지도에 해당 구간 표시. 지도 좌상단 과녁 버튼 → 내 위치 표시.
  • 듣기 → 재생. 재생 중 버전 변경 시 같은 지점에서 이어짐.
  • 멈춰 선 순간만 듣기(기본 켜짐): 녹음하며 멈춰 서 있던 부분만 이어 재생. 발소리 없음. 끄면 구간 녹음 전체 재생.
  • '다음 구간으로 이어 듣기' 켜짐 상태면 구간 종료 후 다음 구간 자동 재생.

걸으며 듣기 (현장)

  1. 부군당에서 걸으며 듣기 탭 → 걷기 시작.
  2. 화면 켠 상태 유지. 주머니에 넣을 때는 주머니 모드(검은 화면, 재생 유지, 1.5초 길게 눌러 해제).
  3. 지점 목록에서 구간별 버전 변경. '모든 구간 한꺼번에'로 일괄 변경 가능.

2. 구글 지도에 코스 넣기

앱 없이 길 확인용. 걷는 길 + 해설 지점 5곳만 담은 KML 파일 제공. 구글 '내 지도'에 가져오면 구글 지도 앱에서 내 위치와 함께 표시.

파일 받기

코스 파일(KML) 받기

점만 필요하면 표 파일(CSV).

내 지도에 가져오기 (컴퓨터 권장)

  1. 구글 계정 로그인 → google.com/mymaps 접속.
  2. 새 지도 만들기. 지도 이름 변경(예: 이태원 소닉워크).
  3. 좌측 '제목 없는 레이어' 아래 가져오기 → 받은 KML 파일 선택.
  4. 파란 선(코스 2: 부군당 → 10.29 골목), 보라 선(코스 1: 우사단로 → 재개발 현장), 지점 5개 표시되면 완료.

휴대폰에서 보기

  1. 구글 지도 앱 → 하단 저장됨.
  2. 맨 아래 지도 → 만든 지도 선택.
  3. 파란 점(내 위치)과 코스 선을 함께 보며 이동. 지점 누르면 이름·설명 표시.
