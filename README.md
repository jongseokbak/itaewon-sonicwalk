# 이태원 소닉워크

이태원 길 위에서, 지금 서 있는 자리의 낮(11/26 13시)과 밤(11/26 19시 30분) 소리를 휴대폰 위치에 따라 듣는 걷기 앱입니다. 설치형 웹앱(PWA)이라 한 번 저장하면 현장에서 인터넷 없이 쓸 수 있습니다.

## 폴더 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 본체 (경로·지점·사진 포함) |
| `sw.js` | 오프라인 저장을 맡는 서비스 워커 |
| `manifest.webmanifest`, `icons/` | 홈 화면 아이콘과 앱 이름 |
| `vendor/leaflet.min.js` | 지도 도구 (Leaflet 1.9.4) |
| `audio/` | 비밀번호로 잠근 소리 네 버전(`*.enc`, v1 낮 68MB, v2 밤 · v3 겹친 시간 · v4 뒤섞인 장소 각 50MB)과 잠금 정보 `lock.json` |
| `map/` | 구글 지도용 코스 파일(KML, CSV) |
| `.nojekyll` | GitHub Pages가 파일을 그대로 내보내게 하는 빈 파일 |

## GitHub Pages에 올리기 (GitHub Desktop 사용)

소리 파일이 25MB를 넘어 github.com 웹 화면의 '파일 올리기'로는 안 올라갑니다. GitHub Desktop을 쓰세요.

1. github.com에 로그인하고, GitHub Desktop(desktop.github.com)을 설치해 같은 계정으로 로그인합니다.
2. GitHub Desktop 메뉴 **File → Add Local Repository…** 에서 이 폴더(`itaewon-sonicwalk`)를 고릅니다. "저장소가 아니다"라는 안내가 나오면 **create a repository** 를 누르고, 이름은 `itaewon-sonicwalk` 그대로 두고 **Create Repository** 를 누릅니다.
3. 오른쪽 위 **Publish repository** 를 누르고, **Keep this code private 체크를 해제**한 뒤 Publish 합니다. (무료 계정의 Pages는 공개 저장소에서만 됩니다.)
4. github.com에서 방금 만든 저장소 → **Settings → Pages** → Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 고르고 Save.
5. 1–2분 뒤 같은 화면 위쪽에 주소가 뜹니다. 보통 `https://계정이름.github.io/itaewon-sonicwalk/` 입니다.

나중에 파일을 고치면 이 폴더에 덮어쓴 뒤 GitHub Desktop에서 Commit → Push 하면 몇 분 안에 반영됩니다.

## 구글 지도용 코스 파일

`map/itaewon_sonicwalk_course.kml`(걷는 길 + 해설 지점 5곳)과 `map/itaewon_sonicwalk_course.csv`(지점만)입니다. 카페·수선집 같은 개인 정보는 빼고 코스만 담았습니다. 앱 아래쪽 '구글 지도에 코스 넣기'에서도 받을 수 있습니다.

1. 컴퓨터에서 KML 파일을 받습니다.
2. google.com/mymaps → 새 지도 만들기 → '제목 없는 레이어' 아래 '가져오기' → 파일 선택.
3. 휴대폰 구글 지도 앱의 '저장됨 → 지도'에서 엽니다.

## 참가자 안내 (그대로 보내도 됩니다)

> **와이파이 되는 곳에서 미리** 아래 순서로 준비해 주세요.
> 1. 링크를 엽니다. 아이폰은 꼭 **Safari**로 여세요.
> 2. 아이폰: 아래쪽 공유 버튼 → **홈 화면에 추가**. 안드로이드: 크롬 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가**.
> 3. 홈 화면에 생긴 **소닉워크** 아이콘으로 앱을 엽니다. (아이폰은 Safari 창이 아니라 이 아이콘에서 저장해야 오프라인에서 보입니다.)
> 4. 맨 위 '오프라인 저장'에 **참가 비밀번호**(진행자가 따로 알려 줌)를 넣고 확인을 누른 뒤, 들을 버전을 **저장**합니다. 한 버전에 50–70MB입니다. 구간마다 다른 버전을 고를 생각이면, 고른 버전을 모두 저장하세요.
> 5. 위치 사용을 묻으면 **허용**합니다.
>
> **현장에서는** 아이콘으로 앱을 열고 '걷기 시작'을 누른 뒤, **화면을 켠 채로** 걸으세요. 화면이 꺼지면 소리도 멈추고, 다시 켜면 지금 위치를 확인한 뒤 그 자리의 소리부터 이어집니다. 휴대폰을 주머니에 넣을 때는 '주머니 모드'(검은 화면, 소리 계속)를 쓰세요. 주변 소리가 함께 들리는 이어폰(투명 모드나 한쪽 귀)을 권합니다.

## 두 가지 듣기

- **걸으며 듣기**: 휴대폰 위치를 따라 지금 서 있는 자리의 녹음이 나옵니다. 지점 목록에서 해설 지점과 그 사이 걷는 길마다 소리 버전(1 낮 · 2 밤 · 3 겹침 · 4 뒤섞임)을 따로 고를 수 있습니다. '모든 구간 한꺼번에'로 한 번에 바꿀 수도 있습니다.
- **구간 골라 듣기**: 위치와 상관없이 구간을 골라 듣습니다. 듣는 도중 버전을 바꾸면 그 구간의 같은 지점에서 이어지고, 구간이 끝나면 다음 구간으로 넘어갑니다(끌 수 있음). 여기서 고른 버전은 걸으며 듣기에도 그대로 쓰입니다.

## 동작 규칙

- 한자리에 머물면 소리가 끊기지 않습니다. 해설 지점에서는 그 지점 녹음 구간을 끝에서 처음으로 겹쳐 이으며 반복하고, 지점 사이에서 멈춰 서면 그 자리 앞뒤 30초씩을 겹쳐 반복합니다. 다시 걸으면 위치를 따라 앞으로 나아갑니다.
- 녹음 사이를 건너뛸 때(구간이 바뀌거나, 반복하거나, 버전을 바꿀 때)는 2.5초 동안 겹쳐 넘어갑니다.

- 화면이 꺼지면 소리를 멈춥니다. 잠금화면의 재생 버튼으로도 다시 켜지지 않습니다.
- 화면을 다시 켜면 새로 잡힌 위치(오차 35m 이내, 15초가 지나면 60m 이내)를 기다렸다가, 경로 전체에서 그 위치를 다시 찾아 해당 녹음 시각부터 서서히 이어 재생합니다. 그사이 지나친 지점은 지난 것으로 처리합니다.
- 걷는 도중(해설 지점 밖) 위치 신호가 20초 넘게 끊기면 소리를 줄여 멈추고, 다시 잡히면 이어집니다. 해설 지점 안에서는 가만히 서 있는 경우가 많아 끊겨도 그 지점의 녹음을 계속 틉니다.
- 경로에서 40m 넘게 벗어나면 멈추고, 돌아오면 이어집니다.
- 바탕 지도는 인터넷이 있을 때 본 부분만 기기에 남습니다(최대 400장). 인터넷이 없으면 지도 일부가 비어도 경로·지점·내 위치는 보입니다.

## 녹음 보호

- 저장소와 사이트는 공개지만, 녹음 파일은 AES-256-GCM으로 암호화되어 있습니다(비밀번호에서 PBKDF2-SHA256 20만 회로 키를 만듦). 비밀번호 없이 받은 파일은 재생되지 않습니다.
- 비밀번호는 이 저장소 어디에도 적지 마세요. 참가자에게는 링크와 따로 알려 주세요.
- 페이지에 검색엔진 색인 거부(noindex)를 넣었습니다.
- 행사가 끝나면 저장소를 비공개로 돌리거나 지우세요. 사이트도 함께 내려갑니다. 이미 저장한 참가자의 휴대폰에는 남습니다.
- 녹음을 다시 잠그거나 비밀번호를 바꾸려면 원본 m4a로 암호화를 다시 해서 `audio/`를 통째로 바꿔 올리고, `index.html`과 `sw.js`의 `sonicwalk-audio-v1`을 `v2`로 올리세요.

## 고칠 때 주의

- 원본 m4a 파일은 이 폴더에 넣지 마세요(`.gitignore`가 막습니다). 한 번이라도 올라가면 기록에 남습니다.
- 파일 하나는 100MB를 넘으면 안 됩니다(git 제한). Git LFS는 쓰지 마세요. Pages가 LFS 파일을 내보내지 않습니다.
